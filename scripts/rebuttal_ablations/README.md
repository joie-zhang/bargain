# Rebuttal ablations

Experiments and diagnostics from the rebuttal phase.

- `context_compaction_pilot.py` generates and runs paired context-compaction batches.
- `analyze_context_compaction_pilot.py` analyzes those paired runs.
- `generate_discount_factor_ablation.py`, `run_discount_factor_ablation_config.py`, and `analyze_discount_factor_ablation.py` generate, run, and analyze the discount-factor experiment.
- `analyze_reviewer_failure_audit.py` summarizes execution failures.
- `analyze_reviewer_item8_n_slope.py` calculates the reviewer-requested group-size comparisons.

Run commands from the checkout root. Saved result locations are unchanged.
