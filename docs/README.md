This directory contains the project documentation.

## Reproduction Records

The dated files record inputs or decisions for specified experiments. Do not treat these files as current procedures.

- The March 31, 2026 LMArena files record the capability values in the paper.
- `appendix_llama33_baseline_experiment_spec_2026_05.md` records the Llama baseline experiment.
- `context_json_repair_2026_04_30.md` records the context and JSON repair design.
- Files in `reference/` record prompt and formalism audits.

## Research Records

The qualitative, related-work, and TTC files are active research records. Some files contain preliminary conclusions.

- Files in `analysis/` contain historical analysis notes.
- Files with `ttc` in their names contain TTC plans or results.
- Files with `QUALITATIVE` in their names contain qualitative analysis plans or results.
- `guides/related_work_deep_dive_2026_04_13.md` supports work on the related-work section.

## Writing Style

The current procedure and reference guides use ASD-STE100 style principles. Project terms and code identifiers are technical nouns.
